# 音樂檔案說明

請將以下音樂檔案放入此資料夾:

- `daily.mp3` - 日常情境音樂 (輕鬆、舒適的背景音樂)
- `christmas.mp3` - 聖誕節音樂 (歡樂的聖誕歌曲)
- `party.mp3` - 派對音樂 (動感、節奏強烈的音樂)
- `halloween.mp3` - 萬聖節音樂 (神秘、詭異的氛圍音樂)

## 檔案格式要求
- 支援格式: MP3, WAV, M4A
- 建議檔案大小: 小於 5MB
- 音質建議: 128kbps 或更高

## 如何取得音樂
您可以從以下來源取得免費音樂:
- YouTube Audio Library (免費無版權音樂)
- Free Music Archive
- Incompetech (Kevin MacLeod 的免費音樂)
- Pixabay Music

**注意**: 請確保使用的音樂沒有版權問題或已獲得適當授權。
